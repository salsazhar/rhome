2. INSTRUMENT CHECK — before any null is believed
------------------------------------------------------------------------------
A 50% result means either 'no signal' or 'the harness is broken', and
those are not distinguishable by staring at the number. Two checks.

  perfect predictor (uses the answer)   143/143 = 100.0%   — must be 100%
  inverted predictor                    0/143 = 0.0%   — must be 0%

  observed residual gap within a pair: median 0.1790,
  90th percentile 0.5314, max 0.9901
  There is real variation to predict; the target is not flat.

------------------------------------------------------------------------------
  engine suppression   71/143 = 49.7%   (p = 1.0000 vs chance)

5. EFFECT-SIZE FLOOR — accuracy against how much is scored
------------------------------------------------------------------------------
A correct direction on a 0.4%-vs-0.2% gap is not information. Raising
the floor should raise accuracy if the signal is real; if it does not,
the engine is right about pairs it barely distinguishes and wrong
about the ones it commits to.

6. CEILING — could this test detect a CORRECT model of this size?
------------------------------------------------------------------------------
Before concluding the model is wrong, ask what the best possible model
of the magnitude the engine predicts would have scored. If the answer
is 'about chance', the null says nothing about the model (D19).

  sd of predicted pair gap   0.0060
  sd of observed pair gap    0.3243
  ratio                      0.0184

  A PERFECT predictor of an effect this size scores 50.6%.
  That is 0.14 SE from chance at n = 143 — NOT detectable.

  So the null is uninformative about correctness. The engine predicts
  effects far below what this measurement can resolve. What the test
  does establish is the effect SIZE, which is a real finding on its own:
  a fatigue model this faint cannot drive a readiness display whatever
  its direction.

  For a perfect model to reach 60% here, the predicted gap would need
  sd 0.105 against the current 0.0060 — 18x larger.

------------------------------------------------------------------------------
7. POWER — what this test could and could not have detected
------------------------------------------------------------------------------
  n = 143 pairs, standard error at chance = 0.042

  a true accuracy of 55%  ->  1.2 SE from chance   NOT detectable
  a true accuracy of 60%  ->  2.4 SE from chance   detectable
  a true accuracy of 65%  ->  3.6 SE from chance   detectable
  a true accuracy of 70%  ->  4.8 SE from chance   detectable

  So this test can find a strong effect and has not. It cannot rule
  out a weak one, and must not be quoted as having done so.
